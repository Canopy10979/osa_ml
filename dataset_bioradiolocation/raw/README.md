# bioradiolocation — raw source

PhysioNet Sleep Bioradiolocation database, 1.6 GB zip (32 subjects,
16-channel contactless radar @ 50 Hz + WFDB `.atr` sleep staging).

**Cohort caveat:** AHI ranges 0.0–4.9 — no subject reaches the AHI >= 5
clinical threshold, so this dataset contains zero OSA cases and cannot support
an OSA-vs-non-OSA label on its own.

Not tracked in git — see `.gitignore`.
